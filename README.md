# ari

4 хуудастай урилга. Утсан дээр нээгдэхээр хийсэн, Швейцарь стильтэй.

```
web/index.html   хуудас бүхэлдээ (HTML + CSS + JS нэг файлд)
web/img/         хаалга бүрийн зургууд (үнэгүй лицензтэй, credit нь хуудсан дээрээ бий)
main.py          FastAPI: хуудсыг өгч, "Send it" дарахад Gmail-ээр имэйл явуулна
requirements.txt
```

## 1. Gmail app password авах

1. https://myaccount.google.com/security руу ороод **2-Step Verification**-ийг асаа.
   Үүнгүйгээр app password үүсгэх цэс гарч ирэхгүй.
2. https://myaccount.google.com/apppasswords руу ороод нэр өг (жишээ нь `ari`) → **Create**.
3. 16 тэмдэгттэй нууц үг гарна. Хуулж аваарай, дахиж харагдахгүй.

Энэ нууц үг зөвхөн Vercel-ийн тохиргоонд орно. Код болон хуудсанд хэзээ ч орохгүй.
Зайтай нь хуулсан ч болно: зай болон хуулахад дагаж ирдэг үл харагдах тэмдэгтийг сервер өөрөө арилгана.

## 2. Vercel дээр үнэгүй байршуулах

1. https://vercel.com → **Add New… → Project** → энэ repo-г (`Buduune/ari`) **Import**.
2. Framework Preset автоматаар **FastAPI** гэж танина. Build тохиргоог хөндөх хэрэггүй.
3. **Environment Variables** хэсэгт:

   | Нэр | Утга |
   |---|---|
   | `GMAIL_ADDRESS` | имэйл илгээх Gmail хаяг (өөрийн чинь) |
   | `GMAIL_APP_PASSWORD` | дээрх 16 тэмдэгттэй app password |
   | `MAIL_TO` | заавал биш. Хариуг өөр хаяг руу авах бол. Өгөхгүй бол `GMAIL_ADDRESS` руу ирнэ |

4. **Deploy**. `https://<project-name>.vercel.app` гэсэн линк гарна.
   Энэ нэр түүнд харагдана, тиймээс project-ийн нэрийг энгийн сонго.

Environment Variables-ийг дараа нь өөрчилбөл **Deployments → Redeploy** хий. Үгүй бол хуучин утгаараа ажилласаар байна.

### Түүнд явуулахаас өмнө шалга

1. `https://<project-name>.vercel.app/api/health` нээ. `"emailConfigured": true`, `"dryRun": false` гэж байх ёстой.
   Энэ нь зөвхөн тохиргоо бөглөгдсөн эсэхийг харуулна. App password зөв эсэхийг 2-р алхам л баталгаажуулна.
2. Хуудсыг өөрөө эхнээс нь дуустал туулж, **Send it** дар. "She said yes" гэсэн имэйл ирэх ёстой.
3. Тэгээд л линкээ түүнд явуул.

Vercel дээр `DRY_RUN`-ийг хэзээ ч бүү тохируул: тэр үед хуудас "My pleasure." гэж харуулах ч имэйл явахгүй.

## Илгээгдэхгүй бол

Илгээж чадаагүй бол хуудас илгээсэн юм шиг хуурамчаар харагдахгүй, юу болсныг хэлнэ. Мессеж бүр өөр шалтгааныг заана:

| Хуудас дээрх мессеж | Шалтгаан | Яах вэ |
|---|---|---|
| Email isn’t set up on the server. | `GMAIL_ADDRESS` эсвэл `GMAIL_APP_PASSWORD` тохируулаагүй | Vercel: **Settings → Environment Variables**-д хоёуланг нь нэмээд **Deployments → Redeploy**. Өөрийн компьютер дээр: доорх 3-р хэсгийн командаар тохируул |
| Gmail refused the login. | Gmail нэвтрэхийг зөвшөөрсөнгүй | `GMAIL_APP_PASSWORD`-д Gmail-ийн энгийн нууц үг биш, 16 үсэгтэй app password байх ёстой. 2-Step Verification асаалттай, `GMAIL_ADDRESS` нь яг тэр app password-ийг үүсгэсэн account эсэхийг шалга. Эргэлзвэл шинэ app password үүсгэж солиод Redeploy |
| The server can’t reach Gmail. | Сервер `smtp.gmail.com:465` руу холбогдож чадсангүй | Өөрийн компьютер дээр бол антивирус эсвэл firewall 465 портыг хааж байж магадгүй. Vercel дээр ховор, хэсэг хүлээгээд дахин оролд |
| There’s no server behind this page. | Хуудас `main.py`-гүйгээр нээгдсэн: файлыг шууд, Live Server-ээр эсвэл Vercel дээр FastAPI биш preset-ээр | Өөрийн компьютер дээр `uvicorn main:app`-аар ажиллуулаад http://127.0.0.1:8000 нээ. Vercel дээр Framework Preset нь **FastAPI** байх ёстой |
| The server didn’t accept the answer. | Хуудас, сервер хоёр өөр хувилбартай | Хуудсыг refresh хийгээд дахин оролд. Давтагдвал Vercel → **Logs**-оос хар |
| Try again in a minute. | Gmail эсвэл сервер түр алдаа өгсөн | Хэсэг хүлээгээд дахин. Давтагдвал Vercel → **Logs**: `Gmail send failed:` гэсэн мөрөнд яг шалтгаан бий |

## 3. Өөрийн компьютер дээр ажиллуулах

macOS / Linux:

```bash
pip install -r requirements.txt
DRY_RUN=1 python -m uvicorn main:app --reload
```

Windows (PowerShell):

```powershell
py -m pip install -r requirements.txt
$env:DRY_RUN = "1"; py -m uvicorn main:app --reload
```

http://127.0.0.1:8000 нээ. `DRY_RUN=1` үед имэйл явахгүй, оронд нь terminal дээр хэвлэгдэнэ.

Жинхэнэ имэйлээр турших бол (PowerShell, шинэ цонхонд):

```powershell
$env:GMAIL_ADDRESS = "you@gmail.com"
$env:GMAIL_APP_PASSWORD = "abcd efgh ijkl mnop"
py -m uvicorn main:app --reload
```

Өмнө нь `DRY_RUN` тохируулсан цонх бол эхлээд `Remove-Item Env:DRY_RUN` гэж арилга.

## Тест

```bash
pip install -r requirements-dev.txt
python -m playwright install chromium
python -m pytest
```

Windows дээр `python`-ий оронд `py` гэж бич: `py -m pip install -r requirements-dev.txt`, `py -m playwright install chromium`, `py -m pytest`.

| Файл | Юуг шалгадаг |
|---|---|
| `tests/test_api.py` | Backend: буруу хариуг татгалзах (огноо, цаг, хаалганы нэр), имэйлийн агуулга, Gmail-ийн зам, илгээж чадаагүй шалтгааныг нэрлэх, давхар имэйлээс сэргийлэх, спамын хязгаар. Жинхэнэ Gmail рүү юу ч явуулахгүй |
| `tests/test_page.py` | Хуудасны текст, зургууд, өнгөний уншигдах байдал, хуудас backend-д яг хэрэгтэй талбаруудыг илгээж байгаа эсэх |
| `tests/logic.test.mjs` | Судоку үргэлж ганц хариутай эсэх, нар жаргах цаг, цагийн формат. Node.js хэрэгтэй, `pytest` өөрөө ажиллуулна |
| `tests/test_e2e.py` | Утасны хэмжээтэй Chromium дээр бүх урсгалыг эхнээс нь дуустал туулна |

Node.js эсвэл Playwright суугаагүй бол тэр хэсэг нь алгасагдана, бусад нь ажиллана.

## Текст, зураг солих

## Хэрхэн ажилладаг вэ

- **Хуудас 1:** NO товч эсвэл түүний ойролцоо хуруу хүрмэгц зугтана (компьютер дээр курсор NO руу ойртоход). YES дээр дарах, YES дээгүүр курсор явуулах нь тооцогдохгүй. Зугтах бүрт NO жижгэрч, YES томорно. 5 удаа зугтсаны дараа "ok fine… yes 🙈" болж 2-р хуудас руу оруулна.
- **Хуудас 2:** түгжээтэй хаалгыг дарахад 4×4 судоку гарна. Хаалга бүрт нэг таавар үүсч, хаагаад дахин нээхэд явц нь хадгалагдана (хуудсыг шинэчилбэл шинэ таавар). Үргэлж ганцхан зөв хариутай, 8 тоо бөглөгдсөн. Эхний хаалгыг тайлсны дараа гурвуулаа нээгдэнэ. Хаалга нээгдэхэд эхлээд зураг, дараа нь төлөвлөгөө гарна. Сайт руу зөвхөн линк дээр дарвал шинэ tab-д нээгдэнэ.
- **Хуудас 3:** маргаашаас хойших өдөр сонгоно (Сиэтлийн цагаар). MoPOP 10:00–17:00 ажилладаг тул 1-р хаалганд 14:00 эсвэл 10:00–15:00 хооронд л сонгоно. "Golden hour" нь сонгосон өдрийн Сиэтлийн нар жаргахаас ойролцоогоор 1 цагийн өмнө.
- **Имэйл:** гарчиг "She said yes". Аль хаалга (дугаар, нэр, төлөвлөгөө), өдөр, цаг, түүний тэмдэглэл, NO-г хэдэн удаа дарах гэж оролдсон, эцэст нь аль товчийг дарсан нь орно. Өдрийн бичвэрийг сервер өөрөө огнооноос бичнэ. Нэг хариулт хоёр удаа имэйлээр ирэхгүй.
- **Спамын хамгаалалт:** нэг хаягаас 10 минутад 8-аас илүү илгээж болохгүй, бүх хүнээс нийлээд 60. Өөр хэн нэгний спам түүний хариуг хаахгүй.
