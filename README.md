# ari

4 хуудастай урилга. Утсан дээр нээгдэхээр хийсэн, Швейцарь стильтэй.

```
web/index.html   хуудас бүхэлдээ (HTML + CSS + JS нэг файлд)
web/img/         хаалга бүрийн зургууд (үнэгүй лицензтэй, credit нь хуудсан дээрээ бий)
main.py          FastAPI: хуудсыг өгч, "Send it" дарахад Gmail-ээр имэйл явуулна
requirements.txt
```

## 1. Gmail app password авах

1. https://myaccount.google.com/security руу ороод **2-Step Verification**-ийг асаа.
   Үүнгүйгээр app password үүсгэх цэс гарч ирэхгүй.
2. https://myaccount.google.com/apppasswords руу ороод нэр өг (жишээ нь `ari`) → **Create**.
3. 16 тэмдэгттэй нууц үг гарна. Хуулж аваарай, дахиж харагдахгүй.

Энэ нууц үг зөвхөн Vercel-ийн тохиргоонд орно. Код болон хуудсанд хэзээ ч орохгүй.

## 2. Vercel дээр үнэгүй байршуулах

1. https://vercel.com → **Add New… → Project** → энэ repo-г (`Buduune/ari`) **Import**.
2. Framework Preset автоматаар **FastAPI** гэж танина. Build тохиргоог хөндөх хэрэггүй.
3. **Environment Variables** хэсэгт:

   | Нэр | Утга |
   |---|---|
   | `GMAIL_ADDRESS` | имэйл илгээх Gmail хаяг (өөрийн чинь) |
   | `GMAIL_APP_PASSWORD` | дээрх 16 тэмдэгттэй app password |
   | `MAIL_TO` | заавал биш. Хариуг өөр хаяг руу авах бол. Өгөхгүй бол `GMAIL_ADDRESS` руу ирнэ |

4. **Deploy**. `https://<project-name>.vercel.app` гэсэн линк гарна.
   Энэ нэр түүнд харагдана, тиймээс project-ийн нэрийг энгийн сонго.

### Түүнд явуулахаас өмнө шалга

1. `https://<project-name>.vercel.app/api/health` нээ. `"emailConfigured": true` гэж байх ёстой.
2. Хуудсыг өөрөө эхнээс нь дуустал туулж, **Send it** дар. "She said yes" гэсэн имэйл ирэх ёстой.
3. Тэгээд л линкээ түүнд явуул.

Тохиргоо дутуу байхад хуудас "Didn’t send" гэж хэлнэ. Илгээсэн юм шиг хуурамчаар харагдахгүй.

## 3. Өөрийн компьютер дээр ажиллуулах

```bash
pip install -r requirements.txt
DRY_RUN=1 uvicorn main:app --reload
```

http://127.0.0.1:8000 нээ. `DRY_RUN=1` үед имэйл явахгүй, оронд нь terminal дээр хэвлэгдэнэ.
Жинхэнээр туршихдаа `DRY_RUN`-ийг аваад `GMAIL_ADDRESS`, `GMAIL_APP_PASSWORD`-оо тохируул.

## Текст, зураг солих

`web/index.html` доторх `DOORS` хэсэгт байгаа: гарчиг, teaser, төлөвлөгөө, сайтын линк, зургууд, зургийн credit.

## Хэрхэн ажилладаг вэ

- **Хуудас 1:** NO товч хуруу хүрмэгц зугтана (компьютер дээр курсор ойртоход). Зугтах бүрт NO жижгэрч, YES томорно. 5 удаа зугтсаны дараа "ok fine… yes 🙈" болж 2-р хуудас руу оруулна.
- **Хуудас 2:** түгжээтэй хаалгыг дарахад 4×4 судоку гарна. Нээх бүрт шинэ, ганцхан зөв хариутай, 8 тоо бөглөгдсөн. Эхний хаалгыг тайлсны дараа гурвуулаа нээгдэнэ. Хаалга нээгдэхэд эхлээд зураг, дараа нь төлөвлөгөө гарна. Сайт руу зөвхөн линк дээр дарвал шинэ tab-д нээгдэнэ.
- **Хуудас 3:** маргаашаас хойших өдөр сонгоно (Сиэтлийн цагаар). MoPOP 10:00–17:00 ажилладаг тул 1-р хаалганд 14:00 эсвэл 10:00–15:00 хооронд л сонгоно. "Golden hour" нь сонгосон өдрийн Сиэтлийн нар жаргахаас ойролцоогоор 1 цагийн өмнө.
- **Имэйл:** гарчиг "She said yes". Аль хаалга (дугаар, нэр, төлөвлөгөө), өдөр, цаг, түүний тэмдэглэл, NO-г хэдэн удаа дарах гэж оролдсон нь орно.
